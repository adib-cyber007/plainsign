# PlainSign

PlainSign is a Chrome extension that will explain Ethereum transaction and signature requests in plain English before the wallet asks the user to approve them. Phase 0 provides the Manifest V3 scaffold, shared types, and bigint-safe bridge utilities; request interception is intentionally not active yet.

## Load unpacked

1. Run `npm install`, then `npm run build`.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select `.output/chrome-mv3`.
